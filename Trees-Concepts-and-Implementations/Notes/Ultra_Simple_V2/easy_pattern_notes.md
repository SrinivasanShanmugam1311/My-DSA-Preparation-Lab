# EASY PATTERN NOTES

## Preorder
Do current work first.

```text
Current -> Left -> Right
```

## Inorder
Use BST sorted order.

```text
Left -> Current -> Right
```

## Postorder
Children answer first.

```text
Left -> Right -> Current
```

## BFS
Process one level at a time.

## Carry downward
Parent passes path, sum, range, maximum, or depth.

## Return upward
Child returns height, pointer, count, state, or best contribution.

## Backtracking
Add, recurse, remove.

## Double DFS
Compare two nodes together.

## BST single path
Compare and move only left or right.

## Tree DP
Children return multiple states.
Parent combines them.
