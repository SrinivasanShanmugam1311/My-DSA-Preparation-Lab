## Study order
Basics → DFS → BFS → height → diameter → balance → same/symmetric → views → boundary → paths → LCA → children sum → complete count → construction → serialization → Morris → invert/flatten → BST → ternary tree.

V3 adds separate practice files for LCA BST, merge BSTs, delete BST, BST from preorder, Morris, diameter, children sum, width, serialization and flattening. Some overlap is intentional.

## Important
Unlike a heap, a tree uses different traversal patterns depending on the required result. The common template is a starting point, not a universal solution. Original packs use different node fields (`val` and `data`); new examples use `val`. Do not mix these APIs without adapting them. Original source correctness has not been audited.
