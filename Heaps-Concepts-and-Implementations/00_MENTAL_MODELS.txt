HEAPS - MENTAL MODELS ONLY
==========================

BASE HEAP
Complete tree in array. Root = current extreme.
INSERT: next empty position -> bubble UP.
DELETE ROOT: last -> root -> heapify DOWN.

01. Min / Max Heap Basics
Heap = complete tree; root keeps the current extreme.
   Root is the extreme; children obey heap rule.
   ↓
   HEAP ROOT = best current candidate

02. Heap Insertion
New item takes next empty seat, then bubbles UP.
   Insert = end, then UP.
   ↓
   HEAP ROOT = best current candidate

03. Delete Heap Root
Last item fills root hole, then moves DOWN.
   Delete root = last to root, then DOWN.
   ↓
   HEAP ROOT = best current candidate

04. Heapify
Fix one wrong parent by pushing it DOWN one path.
   Heapify = choose best child and go DOWN.
   ↓
   HEAP ROOT = best current candidate

05. Build Heap
Leaves are already heaps; fix parents bottom-up.
   Build heap = fix parents bottom-up.
   ↓
   HEAP ROOT = best current candidate

06. Convert Min Heap to Max Heap
Keep the same complete-tree shape; change the rule.
   Min to Max = same tree, opposite comparison.
   ↓
   HEAP ROOT = best current candidate

07. Top K Largest
Keep K winner chairs; root is weakest winner.
   K largest = Min Heap of K winners.
   ↓
   HEAP ROOT = best current candidate

08. Kth Largest
Keep K largest; smallest winner is rank K.
   Kth largest = weakest Top-K winner.
   ↓
   HEAP ROOT = best current candidate

09. Top K Smallest
Keep K smallest; root is worst/largest winner.
   K smallest = Max Heap of K winners.
   ↓
   HEAP ROOT = best current candidate

10. Sort K-Sorted Array
Correct next value must be among next K+1 candidates.
   K-sorted = look at K+1, pop smallest.
   ↓
   HEAP ROOT = best current candidate

11. Merge K Sorted Lists
Each list offers only its current head.
   Pop smallest head; expose next from same list.
   ↓
   HEAP ROOT = best current candidate

12. Replace Elements by Rank
Process values from smallest to largest and assign ranks.
   Smallest first -> assign ranks.
   ↓
   HEAP ROOT = best current candidate

13. Task Scheduler

14. Hand of Straights
